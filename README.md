
# 🚦 Semáforo da Comunicação

## Sobre o projeto

O projeto Semáforo da Comunicação foi desenvolvido utilizando HTML5 e CSS3.

O objetivo é apresentar boas e más práticas de comunicação em interfaces web.

A página utiliza 15 cards divididos em três categorias: verde (boas práticas), amarelo (cuidado) e vermelho (evitar).

O site foi organizado para facilitar a leitura, compreensão e navegação dos usuários.

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub
- GitHub Pages

## Categorias do projeto

### 🟢 Verde – Boas práticas
1. Linguagem clara.
2. Títulos organizados.
3. Bom contraste.
4. Botões claros.
5. Espaçamento adequado.

### 🟡 Amarelo – Cuidado
6. Textos muito longos.
7. Muitas cores.
8. Ícones sem explicação.
9. Muitas informações.
10. Animações frequentes.

### 🔴 Vermelho – Evitar
11. Letras muito pequenas.
12. Baixo contraste.
13. Navegação confusa.
14. Botões sem identificação.
15. Informações somente por cor.

## Práticas de acessibilidade

- Linguagem simples e objetiva.
- Títulos organizados.
- Contraste entre texto e fundo.
- Fonte legível.
- Espaçamento adequado.
- Uso de símbolos e textos explicativos.
- Navegação simples.
- Botões com nomes claros.
- Layout responsivo para celulares.
- Foco visível na navegação pelo teclado.
- Respeito à preferência por movimento reduzido.

## Reflexão

**Por que uma interface não deve depender somente das cores para transmitir uma informação?**

Uma interface não deve depender somente das cores porque nem todas as pessoas conseguem identificar as cores da mesma maneira.

Pessoas com daltonismo ou dificuldades visuais podem ter problemas para diferenciar algumas cores.

Por isso, é importante utilizar também textos, símbolos e títulos explicativos.

Esses recursos ajudam a compreender as informações com mais facilidade.

Assim, a página se torna mais acessível e inclusiva.

A comunicação deve ser clara para todos os usuários.
